# 29. Component Guide

## Frontend React Components

### 1. Common / Shell Components
- **Layout**: Provides top glassmorphic headers, routing paths, responsive sidebar actions, and bottom mobile navigation bars.
- **ErrorBoundary**: Captures client exceptions and renders standard error fallback pages rather than crashing the browser.

### 2. Specialized Components
- **CreatePostForm**: Dynamic social posting input field that expands on focus to reveal post categories, tag selections, and locations.
- **PostCard**: Displays posts with like increments, comment counters, and author profile details.
- **NotificationBell**: Queries for unread alerts. Includes dropdowns to mark individual entries as read or navigate target links.
