# Trust & Reputation System

The Trust System is designed to foster a safe, competitive, and friendly environment across the PlayGrid platform. 

## Philosophy

In community sports, reliability is paramount. The Trust System aims to visually represent a user's reliability and skill level to help Match Creators make informed decisions when approving RSVPs.

## Mechanics

Following the conclusion of a match, participants are prompted to review each other. These reviews aggregate into two distinct metrics:

1. **Reliability Score**: Indicates how often the user shows up when promised, and their general sportsmanship.
2. **Skill Rating**: A crowdsourced assessment of the user's actual sporting ability.

## Badges & Moderation

The system automatically awards badges (e.g., MVP, Fair Play) based on sustained positive reviews. 

Conversely, the platform includes a robust reporting mechanism. Users can flag malicious or toxic behavior, feeding directly into an admin moderation dashboard where platform administrators can issue suspensions or bans to protect the community.
