# 14. Admin Panel

## Purpose
Provides control utilities for platform administrators to monitor health metrics, manage users, and review flags.

## Capabilities
1. **Overview**: Renders counters for total users, matches, venues, and communities.
2. **Moderation Queue**: Resolves pending communities and venue verification requests.
3. **User Management**: Renders paginated listings of registered users and enables administrators to toggle block states (`isBlocked: true/false`).
4. **Reports**: Displays reported posts, comments, or profiles, allowing admins to delete flagged content or block abusive users.
