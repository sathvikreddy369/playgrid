# 25. Future Roadmap

## Proposed Enhancements for V2

### 1. Advanced Venues Booking
- Integrate payment processing APIs (e.g. Stripe or Razorpay) to allow users to book verified venue pitches directly inside PlayGrid.

### 2. PostGIS Spatial Migration
- Upgrade the PostgreSQL database using PostGIS extensions to query coordinates using spatial indexes (`GIST`) for faster response times.

### 3. Progressive Web App (PWA)
- Configure service workers and web push notifications to let mobile users receive notifications without active browser windows.

### 4. Interactive Match Live Scores
- Introduce real-time score updates during match times using custom sockets, allowing players on rosters to log goals, wickets, or scores in real-time.
